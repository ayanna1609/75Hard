# 75 Hard Tracker

A web application to track daily progress for the 75 Hard challenge.

## 🚀 Tech Stack

This project is built with:

- Vite  
- TypeScript  
- React  
- Tailwind CSS  
- shadcn-ui  

## 💻 Running Locally

Make sure you have Node.js installed.

```sh
git clone https://github.com/ayanna1609/75-hard-tracker.git
cd 75-hard-tracker
npm install
npm run dev
